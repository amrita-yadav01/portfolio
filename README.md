# Amruta Yadav — Personal Portfolio Website

A bespoke, editorial, light-theme personal portfolio website designed and developed for **Amruta Yadav** (Second-Year B.Sc. Computer Science student, Pillai College of Arts, Commerce and Science, Pillai University).

---

## 🎨 Design Philosophy & Color Palette

- **Deep Burgundy**: `#5F1D21`
- **Wine Red**: `#7A3035`
- **Muted Burgundy**: `#8B343A`
- **Dusty Rose**: `#B5827C`
- **Blush Beige**: `#E8D4CE`
- **Warm Ivory**: `#FFF9F5`
- **Soft Cream**: `#F6EEE9`
- **Dark Text**: `#332528`
- **Typography**: Playfair Display (Serif), Plus Jakarta Sans (UI & Sans), JetBrains Mono (Code & Metadata)

---

## 🚀 Key Features

1. **Editorial Hero Section**: Prominent portrait framing, verified SGPA 9.77 badge, instant CTAs.
2. **Flagship Projects Showcase**:
   - **UrbanFlow**: Live GIS predictive traffic & accident hotspot intelligence system.
   - **TRAVORA**: Dynamic tour planning & multi-modal itinerary engine (National Hackathon selection).
   - **RASEED**: Duplicate receipt detection & financial expense audit platform (BITFEST 4th Prize).
3. **Beyond the Code — Hackathon Journey**: 4-hackathon interactive timeline with stats (4 Competitions, 2× 2nd Place, 1× 4th Place, 1 National Selection) and authentic certificate previews.
4. **Verified Honors & Certifications**: High-resolution lightbox inspection for Smart India Hackathon, IEEE/TCS Cognithon, and BITFEST 2026 credentials.
5. **Community Leadership**: National Service Scheme (NSS) volunteer engagement at Pillai College.
6. **Visual Gallery**: Photography, achievements, and system UI previews with interactive modal viewer.
7. **Official Resume Section**: Direct PDF download & new-tab viewer linked to `Amruta_Yadav_Updated_Resume.pdf`.
8. **Recruiter-Friendly Contact**: One-click copy for email and phone, verified LinkedIn & GitHub links, and contact form with client-side mail draft launch.
9. **Centralized Configuration**: All text, projects, links, and credentials are maintained in `src/data/portfolioData.js`.

## 🛠️ Local Development & Build

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build optimized production bundle
npm run build

# 4. Preview production build
npm run preview
```
